# داتار | اپلیکیشن نمایشی

این پوشه نسخه وب‌اپلیکیشن تعاملی داتار را در کنار وب‌سایت عمومی شبکه حقوق‌دانان ایران نگهداری می‌کند.

## اجرا
- نشانی آنلاین پس از انتشار GitHub Pages: /app/
- اجرای محلی: پوشه مخزن را با یک وب‌سرور ایستا اجرا کنید و مسیر app/index.html را باز کنید.
- برای نصب روی دستگاه، از قابلیت نصب وب‌اپلیکیشن مرورگر استفاده کنید؛ برنامه دارای Web App Manifest و Service Worker است.

## امکانات نسخه نمایشی
- میزکار و شاخص‌های نمونه
- ثبت و تغییر وضعیت درخواست‌ها
- فهرست اعضا و متخصصان نمونه
- پروژه‌ها و وظایف
- مراکز و کارگروه‌های تخصصی
- ساختار بانک دانش، اسناد و آکادمی
- پیام‌ها و جلسات نمایشی
- بازار خدمات و امور مالی نمونه
- رابط دستیار حقوقی
- گزارش‌ها و مدیریت شبکه
- جابه‌جایی میان سه نقش نمایشی: مدیر شبکه، عضو متخصص و متقاضی خدمات

## وضعیت فنی
این نسخه برای نمایش تجربه کاربری و آزمودن گردش کار ساخته شده است. داده‌های آزمایشی در localStorage همان مرورگر ذخیره می‌شوند و بین دستگاه‌ها همگام نیستند. هیچ اتصال واقعی به پایگاه داده مرکزی، احراز هویت، پرداخت، پیام‌رسان، سرویس هوش مصنوعی یا سامانه ارسال اسناد وجود ندارد.

## مسیر توسعه عملیاتی
۱. طراحی API و پایگاه داده مرکزی  
۲. احراز هویت، مدیریت نشست و کنترل دسترسی مبتنی بر نقش  
۳. گردش کار درخواست، پرونده، ارجاع و ثبت رویداد  
۴. مدیریت اعضا، اعتبارسنجی و تعارض منافع  
۵. مخزن اسناد با سطح دسترسی و نسخه‌بندی  
۶. پرداخت، صورتحساب، سهم همکاران و تسویه  
۷. اتصال بانک قوانین و منابع رسمی با تاریخ اعتبار  
۸. اتصال دستیار هوشمند به منابع مستند و ثبت ارجاع‌ها  
۹. پشتیبان‌گیری، ثبت رخدادهای امنیتی و سیاست نگهداری داده

تمام داده‌های فعلی نمونه هستند و نباید برای تصمیم حقوقی یا مالی واقعی استفاده شوند.
